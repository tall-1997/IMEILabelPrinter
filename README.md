# IMEI 标签打印系统

一款基于 BarTender 2021 的自动化标签打印软件，支持 IMEI 数据录入、自动打印、打印校验和历史管理。

## 功能特性

### 打印录入
- IMEI 输入框，支持扫码枪快速输入
- 数据源名称可配置（默认：IMEI1）
- 打印份数自由设定（1-999）
- 打印前自动校验是否已打印
- 重复打印弹窗确认（可选择放弃或继续）
- 实时打印状态显示和日志记录

### 历史查询
- 按日期范围筛选
- IMEI 关键字搜索
- 完整打印记录表格
- 导出 Excel 功能

### 统计报表
- 按日/月/操作员统计
- 可视化图表展示
- 汇总信息面板
- 多维度数据分析

## 系统要求

### 必需
- **Windows 10/11 操作系统**
- **BarTender 2021 Automation 版**（已安装并激活）
- **Python 3.9+**（开发环境使用，打包后无需安装）

### 可选
- 专用标签打印机（如斑马 Zebra、TSC 等）
- 扫码枪（用于快速录入 IMEI）

## 安装说明

### 方式一：使用打包后的可执行文件（推荐）

1. 双击运行 `build.bat` 进行打包（首次使用）
2. 打包完成后，进入 `dist` 目录
3. 将 `dist` 目录整个复制到目标机器
4. 在目标机器上运行 `IMEI 标签打印系统.exe`

### 方式二：使用源码运行（开发模式）

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 运行程序：
   ```bash
   python main.py
   ```

## 配置说明

### 1. BarTender 模板配置

模板文件需放置在 `templates/` 目录下，默认文件名为 `imei_label.btw`。

**创建模板步骤：**

1. 打开 BarTender 2021
2. 新建标签文档，选择您的打印机和标签尺寸
3. 添加文本对象，双击打开属性
4. 在"数据源"选项卡中，添加数据源，命名为 **IMEI1**（或其他名称）
5. 保存模板到 `templates/imei_label.btw`

详细说明请参考 `templates/README.txt`

### 2. 配置文件

编辑 `config.json` 可修改默认设置：

```json
{
    "template": {
        "path": "templates/imei_label.btw",
        "default_data_source": "IMEI1"
    },
    "excel": {
        "path": "data/records.xlsx"
    },
    "printer": {
        "default_copies": 1,
        "min_copies": 1,
        "max_copies": 999
    }
}
```

### 3. 数据源配置

如果模板中使用了非默认的数据源名称：

1. 启动程序
2. 在"打印录入"标签页
3. 在"数据源名称"下拉框中选择或输入您的数据源名称
4. 进行打印测试

## 使用流程

### 首次使用

1. **准备模板**: 使用 BarTender 创建标签模板，确保包含 IMEI 数据源
2. **放置模板**: 将模板文件 (.btw) 放入 `templates` 目录
3. **启动程序**: 运行 `IMEI 标签打印系统.exe`
4. **配置数据源**: 确认"数据源名称"与模板中的一致
5. **测试打印**: 输入测试 IMEI，打印 1 份确认效果

### 日常使用

#### 打印标签

1. 在"打印录入"标签页
2. 输入或扫描 IMEI（15 位数字）
3. 设置打印份数
4. 点击"打印标签"
5. 系统自动校验并打印
6. 如已打印过，弹窗确认是否继续
7. 打印成功后，自动记录到 Excel

#### 查询历史

1. 切换到"历史查询"标签页
2. 设置日期范围（默认最近 7 天）
3. 可输入 IMEI 关键字筛选
4. 点击"查询"查看记录
5. 点击"导出 Excel"导出数据

#### 查看统计

1. 切换到"统计报表"标签页
2. 选择统计维度（按日/按月/按操作员）
3. 查看图表和统计数据
4. 查看汇总信息（总次数、总份数、日均值）

## 常见问题

### Q1: 程序启动后提示"模板文件缺失"
**A:** 请将您的 BarTender 模板文件 (.btw) 复制到 `templates` 目录，或使用源码运行时修改 `main.py` 中的模板路径。

### Q2: 点击打印后提示"BarTender 初始化失败"
**A:** 
- 确认 BarTender 2021 已正确安装并激活
- 确认 BarTender 是 Automation 版本
- 尝试以管理员身份运行程序
- 检查 BarTender 服务是否正常运行

### Q3: 打印时提示"未找到数据源"
**A:**
- 在 BarTender 中打开模板
- 确认已创建命名数据源（如 IMEI1）
- 确认数据源已关联到文本对象或条码对象
- 在程序的下拉框中选择正确的数据源名称

### Q4: 扫码枪输入后不自动打印
**A:**
- 扫码枪需设置为在 IMEI 后自动添加回车符
- 多数扫码枪默认支持，如不支持请查阅扫码枪说明书
- 或在扫码后手动按回车键或点击"打印标签"按钮

### Q5: 如何修改已打印记录
**A:**
- 打印记录存储于 `data/records.xlsx`
- 可用 Excel 直接打开编辑（程序运行时请勿同时编辑）
- 建议仅追加备注，不要删除记录，以避免重复打印

### Q6: 多操作员如何使用
**A:**
- 程序自动记录当前 Windows 用户名为操作员
- 如需切换操作员，可切换 Windows 用户登录
- 或在打印后手动编辑 Excel 记录修改操作员字段
